## 收藏了很多，认识却没有跟着更新？

一篇资料、一轮讨论、一次纠正，都可能改变你对问题的理解。

Tongle 把这些变化接进同一个知识维护过程：保留依据，整理相关知识，修订已有结论，再把当前有效的知识提供给后续任务。你可以在 Obsidian 或文本编辑器里阅读、修改自己的知识。

## 一条知识，怎样发生变化

以一个**合成示例**说明目标流程：

| 发生的变化 | Tongle 的处理 |
|---|---|
| 你记录「常规发布完成两项检查后可以上线」 | 从来源提炼知识，保留出处与适用条件 |
| 新资料补充「涉及付款的发布还需要人工确认」 | 修订原知识，保留新增例外，避免堆出互相矛盾的重复卡 |
| 你启用了这个主题的综合 | 重新读取主题依据，经过独立内容复核，更新同一张综合卡 |
| 原依据修订或撤回 | 旧综合停止正常提供，等待重新核对 |
| 下一次 AI 处理相关问题 | 提供当前有效知识；是否正确采用，另行记录和验证 |

**知识已更新，不等于 AI 一定用对。** 本版已验证部分生成、修订、停用与送达路径，尚未证明长期任务效果持续提升。上表是机制示例，不是竞品比较成绩。

## 你可以用它做什么

- **长期研究与学习**：将资料、讨论、反例和修订留在同一套有来源的知识里。
- **持续推进项目**：保存决定及理由，在相关任务中取回背景与当前条件。
- **跨工具协作**：按各宿主能力接入 Pi、Codex、Claude Code，共用本地知识。接入方式与验证范围见[连接指南](docs/adapters.md)。
- **自己掌控积累**：知识是可读的 Markdown；来源、版本和处理记录留在本地 SQLite。支持备份与独立恢复。

## 三步开始

1. 从 [Releases](https://github.com/sishuai33-commits/tongle-next/releases/tag/v0.2.0-preview.1) 下载对应系统的包，**完整解压**。
2. Mac 双击 `开始使用.command`，Windows 双击 `开始使用.cmd`。
3. 说明目标，选择少量资料，连接自己的模型，然后启动整理。

独立包自带 Python 运行环境；基础整理无需先安装 Pi、Obsidian 或数据库。Pi 等工具仅在接入对应宿主时需要。**需要你自己的兼容模型接口与额度**；离线可登记、保存和读取资料，新增知识的语义整理需要模型。

这是未签名的终端引导预览版。Mac 仅提供 Apple Silicon 包，Windows 仅提供 x64 包；Intel Mac、Linux 用户可自行运行源码，未作为本次二进制验收目标。系统首次打开可能拦截，请按[快速开始](docs/quickstart.md)核验来源和处理，不要关闭系统的全局安全保护。

源码使用 Python 3.11+：

```sh
git clone https://github.com/sishuai33-commits/tongle-next.git
cd tongle-next
python3 -m tongle.product guide
```

## 知识怎样被维护

`采集来源 → 比较已有知识 → 提出修订 → 独立内容复核 → 发布 → 后续任务使用`

- 新内容优先更新已有知识；没有有效增量时允许不产出。
- 人工编辑、项目范围、来源版本和发布记录由程序核对。
- 调用有预算和有限重试；可查看状态、暂停整理及导出备份。
- **增量主题综合与有界学习为实验功能，默认关闭**，需按项目和主题启用；[配置与范围](docs/topic-synthesis.md)、[使用效果评测](docs/learning.md)有详细说明。

## 数据与模型

资产和来源账本保存在本机。**启用整理后，相关来源及知识正文会发送给你配置的模型服务**；本地存储不等于完全离线处理。请只导入你有权处理的材料。引导不会读取其他 AI 工具的密钥，输入的密钥不写进项目文件；关闭进程后再次使用可能需要重新输入。

## 当前边界

本版不训练大模型，不承诺实现通用 RSI，也不承诺消除幻觉。主题综合首版最多完整读取 12 张卡、16 个来源、48,000 字符；超限会明确等待处理。检索以词法和来源关系为主，仍可能遗漏。宿主升级可能影响自动采集，需要分别验证。

[验证记录](docs/release-validation.md)区分软件测试、合成服务验收和真实模型观察。我们欢迎你反馈：**哪条知识该更新却没更新？哪个任务真正因此变好了？** 请提交脱敏示例，不要上传密钥或完整知识库。

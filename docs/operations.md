# 维护、备份与恢复

产品入口的 `status` 查看状态，`once` 执行一次维护，`start` / `stop` 启动或停止当前实例的后台整理。没有默认开机自启；关闭引导窗口不会自动停止后台进程。

`backup --to 备份.zip` 导出知识、来源、版本及相关状态；只复制 Markdown 不能恢复完整来源账本。`restore --from 备份.zip --vault 新知识目录` 必须使用新的空运行目录，默认关闭模型。恢复后重新核对模型、路径与文件登记。

引导中的“连接模型”只操作当前实例配置，并保留配置备份。密钥不写入配置。不要公开运行库、备份或日志；它们可能含原始资料。

知识整理的成功、送达，以及任务最终正确性是不同状态。发现问题时保留来源与失败状态，优先检查当前实例的“运行情况”，不要反复清空数据重跑。

详细命令见[快速开始](quickstart.md)。主题综合和学习默认关闭，分别见 [topic-synthesis.md](topic-synthesis.md) 与 [learning.md](learning.md)。

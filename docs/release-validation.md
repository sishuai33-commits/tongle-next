# v0.2.0-preview.1 验证范围

本版本基于 2026-10-04 的知识核心，合并已有产品引导和 Windows 可移植层。具体发布验收结果在发布前写入本文件。

## 效果边界

受控的真实模型试验覆盖知识生成、新增例外、分歧、撤回与新会话消费。例外、分歧、撤回场景通过；初始规则题仍有条件误读。没有稳定全通过、自然长期收益或竞品胜出证据。

发布验收的本机回环 HTTP 服务只模拟模型协议，验证安装、处理、修订、检索、回执、备份恢复与后台生命周期，不证明模型智能或真实供应商账户可用。

独立包未签名、未公证。云端 Windows Server 测试不等于普通 Windows 11 桌面首次使用验收。Linux 与 Intel Mac 未提供本次二进制包。

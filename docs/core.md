# 核心边界

SQLite 保存不可变来源快照、版本、事件、任务、撤回标记与修订记录；Markdown 保存可编辑的知识正文。正文由稳定 ID 和内容哈希同步，状态由数据库管理，不把两个副本当成独立真源。

采集提交成功后才回执；采集不等待模型。后台使用持久任务、租约、有限重试和超时。模型结果先落盘再发布，进程中断后可以重放；发布使用独占创建，不覆盖现有笔记。来源变化时旧派生知识退出当前查询。

检索按项目隔离，采用中文双字与英文词项匹配，当前没有向量检索。原话接续与长期提炼并行：近期最多 12 条用户原话，每条最多 3000 字符，适配器注入总量约 6000 字符。旧话不等于当前已确认决定，必须结合时间、来源和状态判断。不能保证任意长对话的所有细节都被召回。

模型只创建候选，必须附原文精确引句和版本。多资料综合至少引用两份当前有效文档；两份文档不等于两个独立事实来源，正确引句也不保证推理正确。明确确认只接受受控操作与用户原话精确对应。人工修改正文回到候选状态，不自动推广成全局规则。

来源暂缺与显式撤回分开：暂缺停止当前使用，恢复后可重新参与；撤回不自动复活。综合笔记任何支撑来源过期都使其退出当前查询。临时阻塞的任务待所需来源全部恢复后继续，已撤回或版本已变的任务终止为 obsolete。

## 当前限制

- 单份导入最多 5 MB；对话采集最多 20 万字符。
- 多资料综合选择最多 8 份当前文档，每份最多 18000 字符；超限明确失败，不声称读完或静默截断。尚无长文分块和大规模资料主题聚类。
- 后台仅跟踪注册文件；没有自动整理旧 Vault、自动合并同义卡或无人审核的永久规则升级。
- Obsidian 只编辑正文；保留身份元数据和正文边界。重复身份会被隔离为冲突，删除文件会退出查询。
- export/restore 包含原始快照、版本和笔记，总展开量上限 100 MB；恢复必须选择空目录，模型授权和运行配置不随包迁移。
- 文件锁通过平台适配支持 macOS/Windows（Linux 源码未作为本次二进制验收目标）。进程间操作有锁；不承诺一个 Engine 对象供任意多线程同时调用。
- 运维提供采集量、任务状态、查询请求数、已观测 token 与耗时。价格未知时不估账单，不能把查询次数视为 AI 实际采用次数。
- 当前没有多日稳定性证据、断电恢复证据、全端自动安装或桌面 GUI。

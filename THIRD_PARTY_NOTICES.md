# Third-party runtime notices

Tongle source is MIT licensed. Downloadable binary bundles include a Python runtime and libraries selected by PyInstaller. These components retain their own licenses; the bundle's `licenses/` folder contains the Python and PyInstaller notices and the build environment's available license files. PyInstaller itself is a build dependency, with an exception permitting distribution of bundled applications under their own licenses.

The source package includes no model weights, API credentials, or third-party agent executables. Pi and other host tools are installed separately by users.
